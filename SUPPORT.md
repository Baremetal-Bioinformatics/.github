# Support

Use the affected repository's issue tracker for reproducible bugs, documentation gaps, and feature proposals. Include the repository revision, platform, input class, exact command, and relevant logs or output differences.

Please use GitHub Discussions when enabled for open-ended design questions. Security issues belong in private vulnerability reporting; see [SECURITY.md](SECURITY.md).

These projects are research and engineering software unless a repository explicitly states otherwise. They are not clinical diagnostic tools and do not provide medical advice.
