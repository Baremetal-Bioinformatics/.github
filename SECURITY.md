# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability involving unsafe memory access, command execution, credentials, private data, or supply-chain integrity.

Use GitHub's private vulnerability reporting feature on the affected repository when available. If it is unavailable, contact an organization owner through GitHub before sharing technical details publicly.

Include the affected repository and revision, impact, reproduction conditions, and any known mitigation. We will acknowledge a complete report as soon as practical and coordinate disclosure after a fix or mitigation is available.

Research-result disagreements, output-compatibility failures, and ordinary bugs can use the public issue tracker unless they expose sensitive data or create a security impact.
